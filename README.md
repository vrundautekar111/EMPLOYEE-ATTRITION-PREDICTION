Employee Attrition Prediction System   
 Project Overview   
 
The Employee Attrition Prediction System is a Machine Learning-based web application designed to predict whether an employee is likely to leave an organization.

The system analyzes employee-related factors such as age, monthly income, job level, years at the company, job satisfaction, work-life balance, overtime, distance from home, and other workplace-related attributes.

A Random Forest Classification model is trained on employee data and integrated with a Flask web application to provide real-time attrition predictions through an easy-to-use web interface.

 Objectives
Predict the likelihood of employee attrition.
Identify employees who may be at high risk of leaving.
Provide an estimated attrition probability.
Help organizations understand factors related to employee turnover.
Demonstrate an end-to-end Machine Learning deployment workflow.
 Features
Employee data input through a web interface
Machine Learning-based prediction
Random Forest classification algorithm 
Attrition probability estimation
High-risk / Low-risk classification
Flask backend API
HTML, CSS and JavaScript frontend
Model evaluation using accuracy and classification metrics 
Saved trained model using Joblib
